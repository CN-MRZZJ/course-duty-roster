# 课表解析与值班优化

`course-duty-roster` 是一个可复用的 AI Agent Skill：从教务课表和补充约束出发，为指定教学周安排值班，并比较不同方案的取舍。

## 支持的材料

- 教务系统导出的 Excel、Word 课表。
- 课程软件截图、照片和多张滚动截图。
- 聊天、口述转写和文字备注中的固定安排、不可排时间及个人偏好。

## 工作流程

1. 确认教学周、日期、班次与每班人数。
2. 解析课程和活动，核对周次、单双周、合并格及截图边界。
3. 建立带来源的可用性矩阵，区分可排、不可排和待核实。
4. 维护硬约束、软偏好和可撤销的约束清单。
5. 用约束优化兼顾实际值班时长、早班分配、单日负担及到岗天数。
6. 核验排班、统计每人负担，交付值班表、缺岗说明和备选方案。

## 使用示例

```text
使用 $course-duty-roster 解析这些课表和聊天约束，
为指定教学周排值班表，每天上午、下午各两班，每班1人。
优先避开课程，值班时长尽量平均，早班尽量分散。
给出推荐方案和备选方案，表中只显示班次。
```

也可以继续提出修改，例如“某位同学周五不能值班”“取消不值早班的偏好”或“比较两天早班与三天早班的方案”。

## 使用边界

这是工作流指令技能，不包含独立运行的课表识别软件或排班求解器。具体执行依赖所用 Agent 环境中的文件读取、图像理解、表格生成及数学求解能力。

隐藏展示钟点不会删除内部时长；未定节次课程需要明确标注。现有人员无法覆盖的班次应保留待补岗，不能安排与课程冲突的人员填补。

仓库只包含通用技能说明和匿名示例，不包含真实学生课表、学号、个人约束或排班结果。
